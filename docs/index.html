west-predictive-methods

Predictive methods from nonlinear dynamics — open code from Western Intelligence LLC (WEST), Director Daniel Patrick Winn.

Bottom line up front: clean, runnable Python implementations of standard methods from nonlinear dynamics and Active Inference, plus a phase-space reconstruction pipeline for multi-channel telemetry. Tested on synthetic Lorenz-63 and Rössler benches only — not real telemetry.

What is in the repo

ModuleWhat it contains
takens_embedding.pyTakens embedding (AMI + false nearest neighbours, phase-space reconstruction)
rosenstein_mle.pyMaximal Lyapunov exponent (Rosenstein, Collins & De Luca 1993), with Theiler-window exclusion

theiler_fnn_pca.pyMultivariate zero-copy strided embedding + Theiler-window-corrected FNN with PCA projection
twrqa_bifurcation.pyPCA-projected sliding-window twRQA + Welford bifurcation detector (NOMINAL / WARNING / BIFURCATION_TRIP)
zmq_streaming_worker.pyAsync ZeroMQ worker: telemetry in on localhost, bifurcation alerts out

Honest limitations

  • The first source is a partial export ("Incomplete Transmission Evaluation", 41 pages) — it ends abruptly mid-table. Nothing has been invented to fill the gap; the truncation is marked INCOMPLETE in ftle.py.
  • Benchmark numbers in the source do not all reproduce (noted in the repo README) — the spectrum reproduces theory, but the source's printed Lorenz/Rosenstein benchmark numbers do not, and one POMDP table is inconsistent.
  • The ZeroMQ streaming worker has not been runtime-tested.
  • All test benches use synthetic Lorenz-63 / Rössler systems, not real telemetry. This is WEST's design, published as code — not a deployed system and not a claim about any live feed.

Run it

pip install -r requirements.txt (Python 3.10+, numpy, scipy; pyzmq and msgpack only for the ZeroMQ worker). Each module is self-contained and runnable — see the repo README for the per-module commands and measured results.
